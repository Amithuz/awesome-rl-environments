# Awesome RL Environments

A curated list of companies, platforms, and open-source projects building reinforcement learning (RL) environments for training and evaluating AI agents.

RL environments are the simulated, resettable settings — a codebase to debug, a browser to navigate, a synthetic enterprise app to operate — where agents attempt real tasks and receive reward signals during reinforcement learning. As gains from pre-training flatten, environments (and the human feedback that grades them) have become one of the most important inputs in frontier AI. This list tracks who's building them.

Maintained as a community list alongside [RL List](https://rl-list.com), a public directory of the space. Contributions welcome.

## Open Source & Tooling

- **[Prime Intellect](https://primeintellect.ai)** — Open superintelligence stack with a public Environments Hub, the PRIME-RL framework, verifiers, and open RL model releases.
- **[HUD](https://hud.ai)** — Wraps arbitrary software (browsers, games, apps) into dockerized, MCP-exposed environments; infrastructure for building your own.
- **[General Reasoning](https://gr.inc)** — Environments and reasoning data for long-horizon, multi-agent reliability, with open community releases.
- **[Bespoke Labs](https://bespokelabs.ai)** — Open datasets and reproducible post-training and evaluation recipes.

## Code & Software Engineering

- **[Mechanize](https://mechanize.work)** — A small set of high-fidelity software-engineering environments and graders for frontier coding agents.
- **[Datacurve](https://datacurve.ai)** — Code-execution and evaluation environments plus coding data for tight training loops.
- **[AfterQuery](https://afterquery.com)** — Benchmark environments for code and finance workflows with real-task framing.
- **[Huzzle Labs](https://labs.huzzle.com)** — Long-horizon coding environments paired with vetted human-expert feedback.

## Browser & Computer Use

- **[Halluminate](https://halluminate.ai)** — Resettable computer-use sandboxes (e.g., a synthetic CRM) and datasets; strong financial-services focus.
- **[Plato](https://plato.so)** — Browser-interaction environments fused with enterprise workflow simulation.
- **[Matrices](https://matrices.ai)** — Browser-native environments for web navigation and interaction tasks.

## Long-Horizon & Reasoning

- **[General Reasoning](https://gr.inc)** — Long-horizon, multi-agent environments and reasoning data.

## Finance & Domain-Specific

- **[Halluminate](https://halluminate.ai)** — Computer-use environments with a financial-services focus.
- **[AfterQuery](https://afterquery.com)** — Code and finance benchmark environments.
- **[Mercor](https://mercor.com)** — Domain-specific environments (code, healthcare, law) sourced through an expert marketplace.
- **[Dissei](https://dissei.ai)** — End-to-end RL environments for institutional finance: financial-reasoning and workflow tasks with verifiable rewards, built by an operating European lender.

## Human-Data Platforms

Companies that grew from human-data and labeling work and now build environments too.

- **[Surge AI](https://surge.ai)** — Bootstrapped human-data leader now building RL environments in-house.
- **[Scale AI](https://scale.com)** — Data-labeling incumbent extending into agents and environments via Forge.
- **[Mercor](https://mercor.com)** — Expert marketplace offering domain-specific environments at frontier scale.
